## Lib Utilities

### `lib/types.ts`
All shared types in a single flat file:

| Type | Shape summary |
|------|---------------|
| `FinancialMetric` | `label, value, change, trend, description` — stat card data |
| `FinancialSummary` | `period, daysElapsed, daysInMonth, daysRemaining` |
| `CostDriver` | `name, amount, percentage, trend, change` — cost breakdown item |
| `ChartDataPoint` | `month, expenses, budget?` — chart data point |
| `Alert` | `id, type (warning/info/success), title, message` |
| `QuickAction` | `id, label, icon` — defined but not yet used in UI |
| `BigQueryDashboardResponse` | Full API response shape: `status, statistics, charts, drilldown, summary, aiInsights` |
| `StatCardProps` | `label, value, change, trend, description?` |
| `AggregatedDashboard` | `statistics, charts, drilldown, summary` — finops-engine output |
| `ServiceCostRow` | `service_description, invoice_month, effective_cost` — SQL GROUP BY result |
| `BillingRow` | Full raw BigQuery billing export row shape (all fields) |

### `lib/utils.ts`
- `cn(...inputs: ClassValue[])` — merges Tailwind classes via `clsx` + `tailwind-merge`

### `lib/env.ts`
- `env` — Zod-validated singleton. Crashes on startup if required vars missing.
- `Env` — TypeScript type inferred from schema
- **Required vars:** `ANTHROPIC_API_KEY`
- **Optional with defaults:** `GCP_PROJECT_ID`, `GCP_CLIENT_EMAIL`, `GCP_PRIVATE_KEY`, `BQ_DATASET`, `BQ_TABLE`, `NODE_ENV`, `LOG_LEVEL`
- **Optional:** `REDIS_URL` (graceful degradation — no Redis = caching disabled)

### `lib/finops-engine.ts`
- `aggregate(rows: ServiceCostRow[]): AggregatedDashboard` — pure, sync. Maps SQL rows → 4 stat cards, chart data, drilldown, summary. Derives current period from data (no hardcoded dates).
- `generateInsights(aggregated: AggregatedDashboard): Promise<Alert[]>` — calls Anthropic `claude-haiku-4-5`, returns 3–5 JSON alerts. Non-fatal: returns `[]` on any error.
- **Re-exports:** all types from `lib/types.ts` for convenience

### `lib/redis.ts`
- `redisGet<T>(key: string): Promise<T | null>` — get + JSON.parse, returns null on miss/error
- `redisSet(key, value, ttlSeconds?): Promise<void>` — JSON.stringify + SET EX, no-op if no Redis
- `TTL` — `{ DEFAULT: 300, HEAVY: 1800, SKIP: 0 }`
- **Graceful degradation:** all ops are no-ops if `REDIS_URL` not set

### `lib/logger.ts`
- `logger` — pino singleton. Pretty-printed in dev (`pino-pretty`), structured JSON in prod.
- Level configured via `LOG_LEVEL` env var (default `info`)

### `lib/query-client.ts`
- `queryClient` — TanStack `QueryClient` singleton. `staleTime: 5min`, `retry: 1`.
