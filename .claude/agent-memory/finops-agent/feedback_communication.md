---
name: Communication Preferences
description: How the user wants the agent to communicate and respond
type: feedback
---

Keep responses concise and action-oriented. User reads fast and prefers bullet points or tables over paragraphs.

**Why:** User is hands-on and practical — they want to move fast, not read essays.

**How to apply:** Lead with the answer, add context only if it changes what to do. Skip trailing summaries ("here's what I did..."). If something is done, just say done.
